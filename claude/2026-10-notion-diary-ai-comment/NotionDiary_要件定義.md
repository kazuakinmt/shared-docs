# NotionDiary 要件定義

最終更新: 2026-10-07

## 1. 目的

Notionの日記に、毎晩自動でタイトルとコメントを付ける。書いた本人が、その日の出来事や気持ちを客観的に振り返れるようにする。

## 2. スコープ

### 対象
- Notionの日記データベースの各ページ(1日1ページ)
- 日記本文の読み取り、タイトルの自動入力、ページ単位のコメント投稿
- 日記に含まれる予定の、Googleカレンダー・タスクへの登録

### 対象外
- 日記の本文の編集(本文は絶対に書き換えない。更新するのはタイトルとコメントだけ)
- InvHub、FBWriterとの統合(独立したプロジェクトとして運用する)

## 3. 動作環境

| 項目 | 内容 |
|---|---|
| 実行場所 | Mac mini(サーバー) |
| 言語 | Python(GASではない) |
| 配置 | `~/developer/NotionDiary/` |
| リポジトリ | GitHub 非公開 |
| 仕様書 | `docs/SPEC.md`、`CLAUDE.md` |
| 開発の進め方 | 設計の相談はチャット、実装はClaude Code(Mac mini) |

## 4. 機能要件

### 4-1. タイトル自動生成
- 日記ページのタイトルを「MM/DD + 約15字の要約」の形式で自動入力する(例:「08/04 〇〇の件、揺れる気持ち」)
- その日いちばん目立つ出来事を要約する
- 個人的な内容も、そのまま要約に出してよい(ぼかさない)
- 既存ページのタイトルも、新形式に上書きする

### 4-2. コメント生成
- 1ページ(1日)につき、コメントは1つだけ投稿する
  - ブロックごとの細かいコメントは、読みにくいので廃止した
- 文体は「冷静で客観的な、個人の研究パートナー」とする
  - 出力は3部構成:状況と思考の整理 / 観察と示唆 / 内省のための問い
- 一般的な話題は、Web検索の結果を踏まえてコメントに組み込む
- 以前の「内面の発見」型のコメントへ戻すときは、プロンプトファイルの差し替えだけで済む構造にする

### 4-3. AIプロバイダーの切り替え
- 分類、日程抽出、タイトル生成は、Claudeに固定する(分類が最も安定しているため)
- コメント生成は、Notionの「AI」プロパティ(選択式)で切り替える
  - クロード / ジェミニ / チャッピー。未選択のときはジェミニ
- システムプロンプトは、プロバイダーごとにMarkdownファイルへ外出しし、コードを触らずに調整できるようにする(`prompts/`)

### 4-4. 予定の抽出と登録
- 日記から日付と予定名を抽出し、Googleカレンダーに登録する
- 予定は人物ごとのカレンダーに振り分ける(家族ごとの専用カレンダー)
- 重複判定を行い、同じ予定を二重登録しない
- 日付があいまいなときは、自動登録せず、確認を求めるコメントを付ける
- 登録したときは、確認のコメントを付ける

### 4-5. 調べ物の依頼への返信
- 「探して」「教えて」のような依頼の文を検出する
- 隣り合うブロックにまたがる条件も、まとめて依頼として扱う
- Webで調べた結果を、コメントで返す

## 5. 非機能要件

### 5-1. 定期実行と信頼性
- launchdで3スロット(23:00 / 23:40 / 00:20)に実行する
- スクリプト内で再試行する
- 翌朝8:00にhealthcheckを実行する

### 5-2. 認証
- Google OAuthは本番公開済み(アプリの正式検証は保留中)
- 認証の失敗で処理が止まったり、失敗したままコメントだけが投稿されたりしないこと
- Mac miniはSSH(ターミナルのみ)で操作するため、再認証の手順は画面なしでも実行できること

### 5-3. 安全性
- APIキーなどの認証情報は、コードに直書きせず、環境変数ファイルで管理する(Git管理の対象外)
- 日記の本文は書き換えない

## 6. 既知の課題

| 課題 | 状態 |
|---|---|
| Googleアプリの正式検証(警告画面を消すため。数週間かかる) | 保留 |
| 失敗通知メールの送信そのもののリトライ | 保留 |
| ジェミニとチャッピーは、分類で過剰に反応しやすい(過去の出来事を予定と誤判定する) | Claude固定で回避済み |

## 7. 今後の要件候補

### 7-1. 過去日記を参照するジャーナリング機能
- 同じタグの過去の日記を参照し、繰り返し出てくるテーマをコメントに織り込む

### 7-2. Strava連携
- その日のStravaの活動データがあれば、日記に書かれていなくても活動記録として載せる
- 未決事項:
  - 表示する場所
  - 日記が空の日の扱い
  - 記載する内容
  - Mac miniからのStrava API認証の方法

## 8. 用語

| 用語 | 意味 |
|---|---|
| 研究パートナー型 | 状況の整理、観察、問いの3部構成で返すコメントの文体 |
| 内面の発見型 | 本人がまだ言葉にしていない気持ちを浮かび上がらせる、以前のコメントの文体 |
| AIプロパティ | Notionのページにある選択式の項目。コメント生成を担当するAIを選ぶ |
